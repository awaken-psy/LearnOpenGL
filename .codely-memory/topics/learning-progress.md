## 关键知识

- 每章 demo 用 `./dev.sh run <chapter>/<demo>` 运行，如 `./dev.sh run 2/1`
- `./dev.sh list` 查看所有可编译 demo
- 代码注释风格：中文，解释"为什么"而非"是什么"，用 `// ----` 分隔逻辑段
- shader 文件与 cpp 放同一目录，命名 `<demo>.<type>.{vs,fs,gs,tcs,tes,cs}`
